# タイミングチャートジェネレータ リリースノート / 移行ガイド

対象: **前回配布版**（2025年12月28日時点、コミット `958454f`）から **現在の版**（2026年9月）までの差分です。

前回配布から約 9 か月分の更新がまとめて入ります。画面の見た目は近いですが、**メニュー項目・チャート操作・書き出し・終了時の確認** が変わっています。初めて新しい版を開くときは、この資料の「まず押さえる操作の違い」から読むことを推奨します。

アプリ内では、右上の **?** または左メニューの **ヘルプ** から、より詳しい操作説明を開けます。メニューの **バージョン情報** にも、変更点の要約があります。

## まず押さえる操作の違い

前回配布版との差で、最初につまずきやすい点です。

### 1. Update Chart は、土台があるまで押せない

以前は起動直後でも押せる印象がありました。今は次のどれかがあって、かつ表示対象の信号名が 1 件以上あるときだけ有効です。

- **Template** を一度実行した
- JSON または `.ziq` をインポートした

信号名を変えたあとにチャートへ反映したい場合は、従来どおり **Update Chart** を使います。波形をゼロから作り直すときは **Template** です。

### 2. チャート下端にマウスを近づけると、横スクロールバーが出る

拡大したあとの左右移動です。表示／非表示のトグルボタンはありません。チャートの**下端付近**にカーソルを置くとバーが出ます。キーボードの ← →（Shift で高速）、PageUp / PageDown、Home / End も従来どおり使えます。

### 3. 選択範囲の外側をクリックすると、選択が解除されるだけ

以前は、選択の外側をクリックするとビットが反転することがありました。今は **選択解除だけ** です。波形を反転したいときは、選択が無い状態でもう一度クリックしてください。

### 4. 鍵アイコンで、波形編集をロックできる

チャート上部の操作バー左端に鍵があります。

- **ロック中**: 波形の 0/1 反転、列の挿入・削除、行の並べ替えはできません
- **ロック中でも可能**: ズーム、スクロール、コメントの閲覧・編集

レビューや画面共有のとき、誤操作防止に使えます。

### 5. コメントをチャートの上側にも置ける

コメント枠をドラッグして、波形の**上側**または**下側**へ移せます。右クリックのプロパティでは、文字色・背景色・折り返し幅・最大行数なども変えられます。文言の一部だけ色を付けることもできます。

### 6. 終了時に「未保存の変更」確認が出る

ウィンドウを閉じるとき、チャートに未保存の変更があると確認ダイアログが出ます。次の操作をしたあとだけ「保存済み」になります。

- JSON のエクスポート
- Clear
- JSON / `.ziq` のインポート

**JPEG / XLSX / HTML だけ書き出しても、未保存のまま**です。資料用に画像を出したあとでも、再編集用に残したい場合は JSON を保存してください。

### 7. 左メニューに項目が増えている

| 新しい項目 | 用途 |
| --- | --- |
| **チャートを末尾に結合...** | 別の JSON チャートを、今の波形の後ろに繋げる |
| **レポートをエクスポート (HTML)** | 構成・信号一覧・カメラ表・チャートを 1 つの HTML にまとめる |

保存が終わると「フォルダを開く」が出せます。保存ダイアログを毎回出したくない場合は、**設定 → I/O** でエクスポート先と **クイック保存** を指定してください。

## 新機能の一覧

### ヘルプ

アプリ内ヘルプを大幅に拡充しました。

- **はじめに**（全体の流れ・メニュー・設定）
- **入力フォーム** / **タイミングチャート** の操作ガイド
- トリガー方式（Single / Code / Command）の説明

右上の **?** を押すと、今開いているタブに合わせたページから始まります。

### 入力フォーム

| 追加・変更 | 内容 |
| --- | --- |
| **補助信号（Auxiliary Signals）** | DIO に紐づかない線（BUSY など）を Add / Remove で増減できます。Code / Command Trigger では `CODE_OPTION` などが自動で足されることがあります |
| **フォーム初期値** | **設定 → 全般** で、起動時と Clear 時のトリガー種別・ポート数・HW・PLC/EIP を覚えさせられます |
| **設定をリセット** | 言語以外の環境設定を初期値に戻せます |
| **Update Chart の有効条件** | 上記「まず押さえる操作の違い」のとおり |

### チャート編集

| 追加・変更 | 内容 |
| --- | --- |
| **編集ロック** | 操作バーの鍵 |
| **横スクロール** | 下端ホバーでバー表示 |
| **0 / 1 キー** | 選択範囲をまとめて 0 または 1 にする（チャートにフォーカスを付けてから） |
| **信号ごとの色** | 左の信号名を右クリック → プロパティ。補助信号は改名も可 |
| **IO 番号表示** | **設定 → 全般** の全体スイッチに加え、行ごとのオン／オフも可能 |
| **上部コメント** | ドラッグで上側へ配置。枠が切れにくいよう余白が広がります |
| **コメントの見た目** | 枠・背景・文字色、破線／矢印、折り返し、最大行数、文言の一部着色 |
| **コードコメント** | Code Trigger の `CODE_OPTION` 上で、制御コード／グループ／タスクからコメント文を組み立てられます（右クリック → **コードコメントを追加**） |

### チャートの結合

左メニュー **チャートを末尾に結合...** で、別 JSON を現在の波形の後ろに連結します。

- チャートが無い初期状態では、通常の JSON インポートと同じ復元になります
- 時間単位（step / ms）が違うときは、今の単位のまま結合するか確認されます
- 相手側にだけある信号は、「0 埋めで行を追加」か「追加しない」かを選べます
- 結合位置にはコメント（既定名は「結合チャート」）が付きます
- 2 本以上つなぐと、チャート上部にセグメント帯が出ます。ドラッグで区間の並べ替え、× でその区間の削除ができます（JSON にも保存されます）

### インポート（.ziq）

| 追加・変更 | 内容 |
| --- | --- |
| **Code Trigger × PLC / EIP** | PLC / EtherNet/IP 構成の Code Trigger を読み込めます。VirtualIO のトリガーポートも扱います |
| **ShutdownMonitor** | 該当設定がある場合に取り込みます |
| **SoftCommandEnable** | 旧データの表記ゆれを正しく解釈します |
| **ビット変化の注釈** | Code Trigger 取込時、ビットが変わった位置に注釈が付きます |

### エクスポート

| 形式 | 前回配布版との差 |
| --- | --- |
| **JSON** | コメントの色・配置（上／下）・折り返しなど、注釈の属性をそのまま保存します |
| **JPEG** | 上部にはみ出したコメントも含め、表示中の見た目を書き出します |
| **XLSX** | 信号色、コメント層、注釈の同期を改善しました。波形は従来どおり罫線で表現します |
| **HTML（新規）** | 構成 / トリガー方式 / 信号一覧 / カメラ取込表 / チャートから、出す項目を選べます。チャートは SVG（拡大・移動・保存が可能）です |

HTML の初期選択は **設定 → I/O** の「HTMLレポートのデフォルト出力項目」で変えられます。書き出しのたびに選び直せます。

### テンプレート波形（再生成時のみ）

**Template** を押し直したとき、一括露光まわりの区切り方が変わっています。

- `BATCH_EXPOSURE` は、待ち（ACQ_TRIGGER_WAITING）を挟む取込があると、そこで一度 Low になります
- `BATCH_EXPOSURE_COMPLETE` は、取込区間（ACQUISITION）の中で `BATCH_EXPOSURE` の反転として入ります

すでに手元にあるチャートを **Update Chart** しただけでは、この波形は作り直しません。新しい区切りに合わせたいときだけ Template してください。既存の手動編集は Template で消えます。

### その他の安定化

- 列削除のあと、波形の同期がずれないようにしました
- Update Chart 時に、チャートの長さを不用意に縮めないようにしました
- デスクトップ版で、終了確認のあとアプリが閉じ残ることがある不具合を直しました

## 推奨する移行手順

新しい exe 一式に差し替えたあと、次の順が安全です。

1. **古い JSON を、新しい版で開いてみる**（左メニュー → インポート）
2. チャートタブで波形・コメントの位置を確認する。上側に置きたいコメントはドラッグで移す
3. 必要なら **設定** で、フォーム初期値・IO 番号表示・信号色・エクスポート先を自分用に直す
4. 問題なければ **JSON で上書き保存**（または別名保存）する
5. 資料用には HTML または XLSX / JPEG を出す

複数シーケンスを 1 本にしたい場合は、土台のチャートを開いてから **チャートを末尾に結合...** を使います。

## よくあるつまずき

| 現象 | 対処 |
| --- | --- |
| **Update Chart が灰色で押せない** | 先に Template するか、JSON / .ziq を開く。信号名が空でないかも確認する |
| **波形をクリックしても反転しない** | 鍵がロックされていないか見る。選択が残っているときは、外側クリックで解除してから押し直す |
| **横にスクロールできない** | チャート下端にマウスを近づける。または ← → / PageUp / PageDown |
| **コメントが上に置けない／切れる** | 枠を上方向へドラッグする。新しい版では上側の余白が広がっています |
| **終了時に確認が出て煩わしい** | 残したい変更は JSON エクスポートする。捨ててよいときは「終了」で閉じる |
| **画像や Excel を出したのに未保存と言われる** | JPEG / XLSX / HTML は保存扱いではありません。再編集用は JSON です |
| **Code Trigger が選べない** | Input Port を 16 以上にする（6 では選べません）。これは従来どおりです |
| **HTML のチャートが動かない** | ブラウザで開いてください。SVG 上で拡大・移動できます |

## 互換性

| データ | 新しい版での扱い |
| --- | --- |
| 前回配布版の **JSON** | 読み込めます。コメントの新しい属性（上配置・文字色など）は、保存し直すとファイルに追加されます |
| 新しい版で保存した **JSON** | 前回配布版では、未知の属性は無視されるか、一部の見た目が再現されないことがあります。配布先を新しい版へ揃えてから共有してください |
| **.ziq** | 従来どおり取り込みます。PLC/EIP の Code Trigger や ShutdownMonitor 付きのデータも対象が広がりました |
| **設定（色・フォルダなど）** | 端末に残ります。大きく変えたいときは **設定 → 全般 → 設定をリセット**（言語は残ります） |
