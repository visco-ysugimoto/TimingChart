前回配布版（2025年12月）からの主な変更です。詳しくは配布資料「リリースノート / 移行ガイド」またはヘルプを参照してください。

### 操作で先に知っておきたいこと
- **Update Chart** は、Template 実行後または JSON / .ziq 取込後で、信号名があるときだけ押せます。
- チャート**下端にマウスを近づける**と横スクロールバーが出ます。
- 選択範囲の外側クリックは、ビット反転ではなく**選択解除**です。
- 操作バーの**鍵**で波形編集をロックできます（ズーム・コメントは可）。
- 終了時、未保存のチャート変更があると確認します。JPEG / XLSX / HTML だけでは保存済みになりません。

### 入力フォーム
- IO に紐づかない**補助信号**を追加・削除できます。
- **設定 → 全般** でフォーム初期値を覚えさせられます。設定リセット（言語以外）もできます。

### チャート
- コメントを**上側**にも置けます。文字色・背景色・折り返し、文言の一部着色ができます。
- 信号ごとの色、行ごとの IO 番号表示ができます。
- Code Trigger では **コードコメントを追加** で制御コードから文言を組み立てられます。
- 別チャートを**末尾に結合**できます。

### インポート / エクスポート
- .ziq: Code Trigger（PLC/EIP 含む）、ShutdownMonitor、ビット変化注釈。
- **HTML レポート**（構成・信号・カメラ表・SVG チャート。出す項目を選択可）。
- XLSX の信号色・コメント反映を改善しました。
- 保存後に**フォルダを開く**、設定の**クイック保存**が使えます。
