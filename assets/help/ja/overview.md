# はじめに

タイミングチャートジェネレータは、検査装置の入出力・HWトリガー・カメラ取込を、**フォーム入力から波形として可視化・編集**するツールです。作成したチャートは JSON / JPEG / XLSX / HTML で書き出せます。

右上の **?** アイコン、または左メニューの **ヘルプ** からこの画面を開けます。開いているタブに合わせて、対応するページが最初に表示されます。

> **コツ:** 初めて使うときは、この「はじめに」→「入力フォーム」→「タイミングチャート」の順に読むと全体の流れが掴みやすいです。

---

## 画面の構成

| 場所 | できること |
| --- | --- |
| **入力フォーム** タブ | トリガー種別、ポート数、信号名、カメラ取込スケジュールを設定する |
| **タイミングチャート** タブ | 波形の確認・編集、コメント・省略記号の追加、ズーム操作 |
| **左上のメニュー（≡）** | インポート / エクスポート / 言語 / 設定 / ヘルプ |
| **右上の言語表示** | 現在の UI 言語（JP / EN）。メニューからも切替可能 |

---

## 基本の流れ

| 手順 | 内容 |
| ---: | --- |
| 1 | **入力フォーム** で Trigger Option・ポート数・信号名・カメラ設定を入力する |
| 2 | **Template** を押して波形の土台を作る（初回は必須） |
| 3 | **タイミングチャート** タブで波形・コメントを確認・編集する |
| 4 | 信号名やポート数を変えたら **Update Chart** で既存チャートへ反映する |
| 5 | 問題なければメニューから JSON / JPEG / XLSX / HTML をエクスポートする |

> **Template** は新規の波形を生成します。**Update Chart** は既存チャート（手動編集を含む）をできるだけ残したまま、フォームの変更を反映します。Update Chart は Template 実行後、またはファイルのインポート後に有効になります。

## メニュー（左ドロワー）

左上の ≡ を開くと、次の項目があります。

### 読み込み

| 項目 | 説明 |
| --- | --- |
| **インポート** | 以前エクスポートした JSON（設定＋波形＋コメント）を読み込みます |
| **チャートを末尾に結合...** | 別の JSON チャートを、現在のチャートの**後ろ**に繋げます |
| **インポート (.ziq)** | 測定データの `.ziq`（zip）からフォームとチャートを復元します |

**.ziq に含まれる主なファイル**

- `vxVisMgr.ini` … トリガー設定や IO 割り当て
- `DioMonitorLog.csv` … DIO のモニタログ
- `Plc_DioMonitorLog.csv` / `FNL_DioMonitorLog.csv` … PLC / FNL 側のログ（あれば使用）

### 書き出し

| 項目 | 説明 |
| --- | --- |
| **エクスポート** | 現在の設定・波形・コメントを JSON で保存します（再編集用） |
| **チャート画像をエクスポート (JPEG)** | 表示中のチャートを画像として保存します |
| **XLSX としてエクスポート** | Excel 用ブックを出力します。波形はセルの**罫線**で表現されます |
| **レポートをエクスポート (HTML)** | トリガー方式・信号一覧・カメラ取込表・チャート画像を 1 つの HTML にまとめます |

保存完了後のメッセージから **フォルダを開く** で出力先を確認できます。

> 保存ダイアログを毎回出したくない場合は、**設定 → I/O** でエクスポート先フォルダと **クイック保存** を指定してください。

### チャートの末尾結合

別チャートを現在の波形の後ろに連結します。

- **時間単位が違う**（step と ms）場合は、現在の単位のまま結合するか確認されます。
- **相手側にだけある信号**がある場合は、「0 埋めで行を追加する」か「追加しない」かを選べます。
- 結合位置にはコメント（既定名は「結合チャート」）が付きます。

### その他

| 項目 | 説明 |
| --- | --- |
| **英語 / 日本語** | UI と言語別の入力候補を切り替えます |
| **設定** | 表示・色・グリッド・エクスポート先などを変更します |
| **ヘルプ** | この画面を開きます |
| **バージョン情報** | アプリの版と変更履歴を表示します |

## 設定

**設定** は左側のカテゴリから選びます。

### 全般

| 項目 | 説明 |
| --- | --- |
| **IO 番号を表示** | チャート左側ラベルにポート番号を付けます。個別のオン/オフはチャート側のラベルプロパティでも変更できます |
| **デフォルトのカメラ数** | 新規作成時の Camera 数（1〜8） |

### チャート

| 項目 | 説明 |
| --- | --- |
| **グリッド線を表示** | 波形エリアの格子の表示 |
| **デフォルトのチャート長** | Template で作る波形の長さ（ステップ数） |
| **信号の色** | 入力 / 出力 / HW トリガー / 補助信号の線色 |
| **コメント関連の色** | 破線・矢印・省略記号の色。個別コメントはチャートのプロパティでも上書きできます |

### I/O（入出力）

| 項目 | 説明 |
| --- | --- |
| **エクスポート先フォルダ（フルパス）** | クイック保存の基準フォルダ。未設定なら保存のたびにダイアログが出ます |
| **クイック保存（ダイアログを省略）** | オンにすると、基準フォルダへすぐ保存します |
| **デフォルトのエクスポートフォルダー** | 基準フォルダ配下のサブフォルダ名 |
| **ファイル名の接頭辞** | 保存ファイル名の先頭に付ける文字列 |

### 表示 / 言語

- **ダークモード** と **アクセントカラー** で見た目を変えられます。
- 言語は設定画面、または左メニューの「日本語 / 英語」からも切り替えられます。入力候補（サジェスト）も言語に追従します。
