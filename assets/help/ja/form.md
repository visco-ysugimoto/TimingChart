# フォーム画面のヒント

## 基本操作

| 操作 | 説明 |
| --- | --- |
| **Tab / Shift+Tab** | 入力項目の移動 |
| **Enter** | 入力確定（項目によって挙動が異なります） |
| **Update Chart** | フォーム内容をチャートへ反映 |

## 推奨ワークフロー

| 手順 | 内容 |
| ---: | --- |
| 1 | トリガー・ポート数・信号名を入力 |
| 2 | **Update Chart** でチャートタブを確認 |
| 3 | 問題なければ JSON / XLSX / 画像でエクスポート |

## インポート / エクスポート

| 機能 | 説明 |
| --- | --- |
| **インポート** | 保存済み JSON 設定を読み込み |
| **インポート (.ziq)** | ZIQ からフォーム・チャートを復元 |
| **エクスポート** | 現在の設定を JSON で保存 |

## コツ

- まずは入力後にチャートタブへ切り替え、波形表示が意図通りか確認してください。
- エクスポート先フォルダは **環境設定 → 入出力** で指定できます（クイック保存に利用）。
