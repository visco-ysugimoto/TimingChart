# 入力フォーム画面

この画面で、チャートに載せる**信号の構成**と**カメラ取込の順番**を決めます。上段が全体設定、左下が信号名、右下が Camera Configuration Table です。

---

## 推奨ワークフロー

| 手順 | 内容 |
| ---: | --- |
| 1 | 上段で Trigger Option・PLC/EIP・ポート数・カメラ数を選ぶ |
| 2 | 左の欄に信号名を入れる（入力候補から選べます） |
| 3 | 右のテーブルで各カメラの取込モードを設定する |
| 4 | **Template** で波形を生成し、チャートタブで確認する |
| 5 | あとから名前や台数を変えたら **Update Chart** で反映する |

> チャートがまだ無い状態では Update Chart は押せません。先に Template を実行するか、JSON / .ziq をインポートしてください。信号名が 1 件も無い場合も無効になります。

---

## 上段の設定

| 項目 | 選択肢 / 範囲 | 説明 |
| --- | --- | --- |
| **Trigger Option** | Single / Code / Command | トリガー方式。Code Trigger は Input Port が 6 のときは選べません |
| **PLC / EIP** | None / PLC / EIP | PLC または EtherNet/IP のチャンネルを使うかどうか |
| **Input Port** | 6 / 16 / 32 / 64 | 入力信号の本数 |
| **Output Port** | 6 / 16 / 32 / 64 | 出力信号の本数 |
| **HW Port** | 0 または Camera 数と同じ | 0 だと HW トリガー欄は使えません。カメラ台数に合わせると 1 台につき 1 本になります |
| **Camera** | 1〜8 | カメラ台数。テーブルの列数と連動します |

### Trigger Option の違い

| 方式 | 用途の目安 |
| --- | --- |
| **Single Trigger** | 通常の単発トリガー。入力 1 本目は TRIGGER として扱われます |
| **Code Trigger** | グループ / タスクなどをコードで指定する方式。対象ポートは名前が固定され編集できません。補助信号 `CODE_OPTION` が自動で追加されます |
| **Command Trigger** | コマンド指定のトリガー。補助信号 `Command Option` などが自動生成されます |

### PLC / EIP を選んだとき

入力・出力の見出しに **DI / PLI/ESI**、**DO / PLO/ESO** のタブが現れます。

- **DI / DO** … 装置側の DIO
- **PLI / PLO** … PLC 側（PLC 選択時）
- **ESI / ESO** … EtherNet/IP 側（EIP 選択時）

右上に **DI⇔PLI/ESI** と **DO⇔PLO/ESO** ボタンが出ます。同じ並びの信号名を、DIO 側と PLC/EIP 側のあいだで入れ替えます。

---

## ボタン

| ボタン | 動作 |
| --- | --- |
| **Clear** | フォーム上の信号名などをクリアします（確認してから使ってください） |
| **Template** | 現在の設定とカメラテーブルから、テンプレート波形を**新規生成**します。チャートの土台作りに使います |
| **Update Chart** | 既存チャートへフォーム内容を反映します。チャート上で直した波形は、可能な限り残します |
| **DI⇔PLI/ESI** / **DO⇔PLO/ESO** | PLC/EIP 使用時のみ。DIO と PLC/EIP の信号名を入れ替えます |

> エクスポート前に、最新のフォーム内容をチャートへ載せたい場合は Update Chart を押してから書き出してください。

---

## 信号名の入力

左下は 3 列です。**Input Signals** / **Output Signals** / **HW Trigger Signals**。HW の下に **Auxiliary Signals**（補助信号）があります。

### 共通の操作

| 操作 | 説明 |
| --- | --- |
| **文字入力** | 信号名を入力します。候補リストから選べます（重複名は避けてください） |
| **右側のチェックボックス** | オンの信号だけがチャートに表示されます。オフにすると波形行から隠れます |
| **Tab / Shift+Tab** | 次 / 前の入力欄へ移動 |
| **Enter** | 入力の確定（欄によって動きが少し違います） |

名前の候補は、メニューの言語設定に合わせて日本語 / 英語が切り替わります。

### Input / Output

- ポート数を増やすと入力欄が増えます。減らすと末尾から消えます。
- Code Trigger のとき、制御・グループ・タスク用の入力は灰色でロックされ、名前を変えられません。チャート上でも該当ビットは専用の扱いになります。

### HW Trigger

- **HW Port が 0** のときは「HW Trigger Ports are not available.」と表示され、テーブルでも HWトリガ は選べません。
- Camera 数と同じにすると、カメラ台数分の HW トリガー名を入力できます。

### Auxiliary Signals（補助信号）

DIO 以外の補助ライン（BUSY など）を追加できます。

| 操作 | 説明 |
| --- | --- |
| **Add** | 補助信号を 1 本追加 |
| **Remove** | その行を削除 |
| チェックボックス | チャートへの表示 / 非表示 |

Code / Command Trigger では `CODE_OPTION` などの補助信号が自動で足されることがあります。名前の重複には注意してください。

## Camera Configuration Table

右下の表で、**いつ・どのカメラを・どの方式で取り込むか** を決めます。Template はこの表を見て波形を組み立てます。

### 行と列

- 列は Camera 1, 2, …（Camera 数に連動）
- 行は取込のステップ。**Add Row** / **Remove Row** で増減します（最低 1 行）

### セルのモード

各マスのドロップダウンでモードを選びます。色でも区別できます。

| モード | 意味 |
| --- | --- |
| **None** | そのステップでは取り込まない |
| **順次取込** | ソフト側の順次取込 |
| **接点入力** | 接点入力待ちで取込 |
| **HWトリガ** | ハードウェアドリガーで取込（HW Port が 0 のときは選べません） |

### 便利な操作

| 操作 | 動作 |
| --- | --- |
| **列見出し（Camera n）をクリック** | そのカメラ列を、同じモードで一括変更 |
| **左端の行番号をクリック** | **同時取込** のオン/オフ。オンだと行がティール色になり、同じ行のカメラを同時に取り込む設定になります |

> 同時取込は「同じタイミングで複数カメラを撮る」行です。順次取込の行と混ぜて、実際の検査シーケンスに近い表を作れます。

---

## よくあるつまずき

- **Update Chart が押せない** … まだ Template もインポートもしていないか、表示対象の信号名が空です。
- **HWトリガがテーブルに出ない** … HW Port を Camera 数と同じにしてください。
- **Code Trigger がリストに無い** … Input Port を 16 以上にしてください（6 では選べません）。
- **チャートに信号が出ない** … チェックボックスがオフになっていないか、Template / Update Chart を実行したかを確認してください。
