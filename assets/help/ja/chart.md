# チャート画面のヒント

## キーボード（横移動）

| キー | 動作 |
| --- | --- |
| **← / →** | 横移動（**Shift** で高速） |
| **PageUp / PageDown** | 1 画面分の横移動 |
| **Home / End** | 先頭 / 末尾へ移動 |

## ズーム・編集

| 操作 | 動作 |
| --- | --- |
| **Ctrl / Cmd + ホイール** | ズーム（カーソル位置基準） |
| **Ctrl / Cmd + Z** | Undo |
| **Ctrl / Cmd + Y** | Redo |
| **Ctrl / Cmd + A** | 全選択 |
| **0 / 1** | 選択範囲を 0 / 1 に設定 |

## マウス

| 操作 | 動作 |
| --- | --- |
| **ドラッグ** | 範囲選択（またはアノテーション操作） |
| **右クリック** | コンテキストメニュー |
