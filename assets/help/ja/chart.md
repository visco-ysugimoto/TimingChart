# タイミングチャート画面

フォームで作った波形を表示・編集する画面です。クリックやドラッグでビットを直し、コメントや省略記号を付けられます。編集結果は JSON / JPEG / XLSX / HTML に含まれます。

> 波形を大きく変えたい場合は、先にフォームで Template し直すか、必要な範囲だけ選択して右クリックメニューを使うと安全です。

---

## 画面上部のコントロール

チャートの上（または近く）に操作バーがあります。

| 項目 | 説明 |
| --- | --- |
| **鍵アイコン** | チャート編集のロック。ロック中は波形の反転・挿入・削除・行の並べ替えができません（閲覧・ズーム・コメント操作はできます） |
| **Unit** | 横軸の単位。オフが **step**（ステップ番号）、オンが **ms**（ミリ秒） |
| **Labels** | 下部の時間ラベル（目盛り数字）の表示 |
| **Edit grid** | 単位が **ms** のときだけ。グリッド境界をドラッグして各ステップの長さを変えられます。終わったら **Done** |
| **Undo / Redo** | 編集の取り消し / やり直し（Ctrl+Z / Ctrl+Y でも可） |
| **Zoom out / Zoom in** | 画面中央を基準に縮小 / 拡大。現在倍率が % で表示されます |
| **Fit** | 全体が収まる倍率に戻す |
| **Fit sel** | 選択範囲が画面に収まるよう拡大（範囲選択中のみ） |
| **Sel** | 選択範囲の長さ。ms モードならミリ秒、step モードならステップ数 |

---

## マウス操作

| 操作 | 動作 |
| --- | --- |
| **波形セルをクリック** | その位置の 0 / 1 を反転。範囲選択中なら、選択内をまとめて反転します |
| **ドラッグ** | 矩形で範囲選択（行×時間）。選択中はハイライトされます |
| **左の信号名をドラッグ** | 行の並べ替え |
| **コメント枠をドラッグ** | コメントの位置を移動。チャートの上側 / 下側へも置けます |
| **右クリック** | クリック位置に応じたメニュー（波形 / ラベル / コメント） |
| **Ctrl（または Cmd）+ ホイール** | カーソル位置を中心にズーム |
| **画面下端にマウスを近づける** | 拡大時、横スクロールバーが表示されます。つまみをドラッグして移動 |

ロック中は波形のクリック反転や並べ替えは無効です。鍵アイコンで解除してください。

## キーボード

チャートをクリックしてフォーカスを付けてから使います。

### 表示位置（横移動）

| キー | 動作 |
| --- | --- |
| **← / →** | 少しずつ横移動。**Shift** を押しながらで速く動きます |
| **PageUp / PageDown** | 画面 1 枚分の横移動 |
| **Home / End** | 先頭 / 末尾へジャンプ |

### 編集

| キー | 動作 |
| --- | --- |
| **Ctrl / Cmd + Z** | Undo |
| **Ctrl / Cmd + Y** | Redo |
| **Ctrl / Cmd + A** | 全信号・全時間を選択 |
| **0** | 選択範囲をすべて 0 にする |
| **1** | 選択範囲をすべて 1 にする |

## 右クリックメニュー（波形エリア）

波形上（ラベルでもコメントでもない場所）で右クリックします。選択範囲があるかどうかで項目が変わります。編集ロック中は波形変更系が隠れます。

| 項目 | 説明 |
| --- | --- |
| **0 を挿入** | 選択した時間幅ぶん、0 の列を挿入して後ろをずらします |
| **末尾に複製** | 選択範囲の波形をチャートの一番後ろにコピーします |
| **すべての信号を選択** | 全行・全時間を選択（Ctrl+A と同じ） |
| **選択範囲を削除** | 選択したセルの値を消す（長さは維持） |
| **選択列を削除** | 選択した時間列そのものを削除し、チャートを短くします |
| **コメントを追加** | クリック位置（または選択範囲）にコメントを付けます。範囲選択中は範囲コメントになります |
| **省略記号** | 選択した時間に波線（省略）を描きます。長い待ち時間などを省略表示するときに使います |

## 信号ラベルのプロパティ

左の信号名の上で右クリック → **プロパティ**。

| 項目 | 説明 |
| --- | --- |
| **ラベル名** | 表示名。補助信号はここから改名できます（空欄・他信号との重複は不可） |
| **色** | 補助信号の線色 |
| **IO番号を表示** | その行だけポート番号の表示を切り替えます。設定の「IO 番号を表示」がオフのときは変更できません |

## コメント（注釈）

手順の説明や信号の意味を、波形の上または下に枠付きで置けます。

### 追加・編集

1. 波形上で右クリック → **コメントを追加**（範囲を選んでからだと範囲コメント）
2. テキストを入力して OK
3. 枠をドラッグして位置調整。上側へ運ぶとチャート上部、下側へ運ぶと下部に配置されます

コメント枠を右クリックすると、次のメニューが出ます。

| 項目 | 説明 |
| --- | --- |
| **コメント編集** | 文言の変更。文字列の一部を選んで **選択範囲の色** を付けることもできます |
| **コメントを削除** | そのコメントを消します |
| **水平矢印をオフ / オン** | 矢印を水平に伸ばすか、行に向けて斜め（または縦）にするか |
| **矢印の先端をこの行に設定** | 水平矢印がオフのとき、今右クリックした行へ矢印の先を向けます |
| **プロパティ** | 見た目の詳細設定 |

### プロパティで変えられること

| 項目 | 説明 |
| --- | --- |
| **フォントサイズ / 太字** | 文字の大きさ（8〜40）と太字 |
| **枠線 / 背景 / 文字色** | 枠の色（透明も可）、塗り、文字色 |
| **破線の色 / 表示** | コメントから時刻位置へ下ろす（または上げる）点線 |
| **矢印の色 / 表示** | 参照先を示す矢印 |
| **折り返し幅** | 1 行の幅。狭いと自動で改行されます |
| **最大行数** | 表示行数の上限。「無制限」にもできます |
| **省略記号 (...)** | 行数オーバー時に末尾を `...` にするか |

既定の破線色・矢印色は **設定 → チャート** でも変えられます。個別のプロパティが優先されます。

## 省略記号（波線）

長い定常区間などを折りたたんで見せる印です。

1. 省略したい時間範囲をドラッグ選択する
2. 右クリック → **省略記号**

色は **設定 → チャート → 省略記号の色** で変更できます。

---

## 時間単位とグリッド編集

- **step** … 1 マス = 1 ステップ。マス目が等間隔です。
- **ms** … 各ステップに実時間（ミリ秒）が付きます。.ziq インポート時はログの間隔から自動で入ります。

**ms** のとき **Edit grid** を押すと、縦の境界線をドラッグ（またはタップ）して、ステップごとの長さを調整できます。調整が終わったら **Done** を押してください。単位を step に戻すと、グリッド編集は終了します。

---

## Undo / Redo とロック

- 波形の反転、挿入・削除、並べ替え、コメント変更などは Undo / Redo の対象です。
- ロック（鍵）を掛けると、誤って波形を壊す操作を防げます。レビューや画面共有のときに便利です。

---

## 画像・表への書き出し

チャートタブで見た目を整えてから、左メニューで出力します。

| 形式 | 向いている用途 |
| --- | --- |
| **JPEG** | 資料・メールに貼る画面イメージ。ズームやコメントの見え方が画像に反映されます |
| **XLSX** | Excel で波形を罫線として確認・共有する。コメントの枠色なども可能な範囲で反映されます |
| **JSON** | 後からアプリで開き直して編集を続ける |

> フォームを直した直後は、**Update Chart** してからエクスポートすると、ファイルの内容が画面と一致します。
