# コードトリガ（Code Trigger）

同時に複数の入力信号を使い、**2 進のコード** でタスクのロード・実行・アンロードなどを指定します。制御コード・グループ番号・タスク番号をビットの組み合わせで表します。

## 操作の流れ

1. 制御コード・グループ・タスクのビットをセットする
2. **入力 1（トリガ）を ON** して実行する
3. 入力 1 を OFF してから、次のコードをセットする

実行後にトリガを落とさないと、次のコードを受け付けられません。

## ビット割り当て

入力ポート数によって割り当てが変わります。いずれも **入力 1 がトリガ** です。Control / Group / Task の信号名は固定です。合成信号 `CODE_OPTION` はこれらのビットの論理和です。

### 32 ポート

| 役割 | 入力ポート | ビット数 | 意味 |
| --- | --- | ---: | --- |
| トリガ | Input 1 | — | コード確定・実行 |
| Control Code | Input 2〜9 | 8 | 制御コード（コマンド種別） |
| Group | Input 10〜15 | 6 | グループ番号（1〜50 を 2 進で指定） |
| Task | Input 16〜21 | 6 | タスク番号（1〜50 を 2 進で指定） |

6 bit を 10 進に変換し、グループ / タスク番号 1〜50 に割り当てます。

### 16 ポート

| 役割 | 入力ポート | ビット数 |
| --- | --- | ---: |
| トリガ | Input 1 | — |
| Control Code | Input 2〜5 | 4 |
| Group | Input 6〜8 | 3 |
| Task | Input 9〜14 | 6 |

## 制御コード（10進 / 8 bit）

コードをセットしたあと、入力 1（トリガ）を ON すると実行されます。
8 bit は Input 9 → Input 2 の順（左が MSB）です。制御側にはこの 8 bit を入力します。

| 10進 | 8 bit | コマンド |
| ---: | --- | --- |
| 1 | `00000001` | タスク実行 |
| 2 | `00000010` | システムコマンド実行 |
| 3 | `00000011` | アクティブタスク切り替え |
| 4 | `00000100` | タスクロード |
| 5 | `00000101` | タスクアンロード |
| 9 | `00001001` | アクティブタスク実行 |
| 10 | `00001010` | 判定値カウンタクリア |
| 12 | `00001100` | 全タスクアンロード |
| 34 | `00100010` | ロット開始 |
| 35 | `00100011` | ロット終了 |
| 37 | `00100101` | 画像保存開始 |
| 38 | `00100110` | 画像保存終了 |
| 39 | `00100111` | 画像ファイル保存 |
| 40 | `00101000` | ロット設定編集 |
| 42 | `00101010` | システムシャットダウン |
| 43 | `00101011` | 画面ファイル保存 |
| 44 | `00101100` | 画面保存開始 |
| 45 | `00101101` | 画面保存終了 |
| 48 | `00110000` | 分散運用開始 |
| 49 | `00110001` | 分散運用終了 |

## 使用例

グループ 10 / タスク 5 をロードして実行する流れです（**32 ポート**）。
各手順は「コードをセット（トリガ OFF）→ トリガ ON で実行」の組です。

ビットの向きは次のとおりです。

- 制御コード: Input 2 が LSB、Input 9 が MSB（8 bit）
- グループ: Input 10 が LSB、Input 15 が MSB（6 bit）
- タスク: Input 16 が LSB、Input 21 が MSB（6 bit）

| 手順 | 内容 | 制御コード | グループ | タスク | トリガ (Input1) | ON にする入力 |
| ---: | --- | ---: | ---: | ---: | --- | --- |
| 1 | 全タスクアンロードを設定 | 12 (`00001100`) | 0 | 0 | OFF | Input 4, 5 |
| 2 | 全タスクアンロードを実行 | 12 (`00001100`) | 0 | 0 | ON | Input 1, 4, 5 |
| 3 | タスクロードを設定 | 4 (`00000100`) | 10 (`001010`) | 5 (`000101`) | OFF | Input 4, 11, 13, 16, 18 |
| 4 | タスクロードを実行 | 4 (`00000100`) | 10 (`001010`) | 5 (`000101`) | ON | Input 1, 4, 11, 13, 16, 18 |
| 5 | タスク実行を設定 | 1 (`00000001`) | 10 (`001010`) | 5 (`000101`) | OFF | Input 2, 11, 13, 16, 18 |
| 6 | タスク実行 | 1 (`00000001`) | 10 (`001010`) | 5 (`000101`) | ON | Input 1, 2, 11, 13, 16, 18 |
| 7 | トリガを OFF | 1 (`00000001`) | 10 (`001010`) | 5 (`000101`) | OFF | Input 2, 11, 13, 16, 18 |
| 8 | 同じコードで再度実行 | 1 (`00000001`) | 10 (`001010`) | 5 (`000101`) | ON | Input 1, 2, 11, 13, 16, 18 |

制御コード 12 / 4 / 1 は、上の制御コード表の「全タスクアンロード」「タスクロード」「タスク実行」に対応します。
`00001100` などは Input 9 → Input 2 の順（左が MSB）です。
