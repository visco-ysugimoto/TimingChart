# 単接点トリガ（Single Trigger）

自動運転中、ある入力信号に **起動信号（Lo→Hi）** を入れると、その接点にあらかじめ割り振られたタスク、またはシステムコマンドを起動できます。

**入力 1 本に対してタスク 1 つ** を割り当てます。1 本目の入力は `TRIGGER` です。

## 特徴

- 配線と接点の対応が分かりやすい
- 品種（タスク）の切替は、使える接点の本数までに限られる

## 使用例

同じ入力（入力 1）の立ち上がりで、割り当ての違うタスクを順に起動する例です。

| 手順 | 動作 |
| ---: | --- |
| 1 | 入力 1 でグループ 01 / タスク 01（G01T01）の検査開始 |
| 2 | 入力 1 でグループ 01 / タスク 05（G01T05）の検査開始 |
| 3 | 入力 1 で G01T01 の検査開始 |
| 4 | 入力 1 で G01T05 の検査開始 |

実際にどの接点へどのタスクを割り振るかは、装置側の設定に従います。

## 32 入力の典型例（VTV9000）

| 入力 | 用途の例 |
| ---: | --- |
| 1〜10 | タスク起動用トリガ（Task G01T01 〜 G01T10 など） |
| 11〜19 | 追加のトリガ入力 |
| 22〜29 | カメラ列実行制御（Cam1〜Cam8） |
| 30 | 接点入力待ち解除 |
| 32 | システム起動保持信号 |
