# Form tips

## Basic operations

| Action | Description |
| --- | --- |
| **Tab / Shift+Tab** | Move between fields |
| **Enter** | Commit input (behavior depends on the field) |
| **Update Chart** | Apply form data to the chart |

## Recommended workflow

| Step | What to do |
| ---: | --- |
| 1 | Enter trigger, port counts, and signal names |
| 2 | Click **Update Chart** and review the Chart tab |
| 3 | Export as JSON, XLSX, or image when satisfied |

## Import / export

| Feature | Description |
| --- | --- |
| **Import** | Load a saved JSON configuration |
| **Import (.ziq)** | Restore form and chart from measurement ZIQ |
| **Export** | Save the current configuration as JSON |

## Tips

- Switch to the Chart tab after editing to verify waveforms.
- Set a default export folder under **Settings → I/O** for quicker saves.
