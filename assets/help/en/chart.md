# Chart tips

## Keyboard (horizontal pan)
- **Left / Right**: Pan horizontally (**Shift** to accelerate)
- **PageUp / PageDown**: Pan by one viewport
- **Home / End**: Jump to start / end

## Zoom
- **Ctrl/Cmd + Wheel**: Zoom in/out
