# Chart tips

## Keyboard (horizontal pan)

| Key | Action |
| --- | --- |
| **← / →** | Pan horizontally (**Shift** to accelerate) |
| **PageUp / PageDown** | Pan by one viewport |
| **Home / End** | Jump to start / end |

## Zoom and editing

| Action | Effect |
| --- | --- |
| **Ctrl / Cmd + Wheel** | Zoom in/out (cursor-centered) |
| **Scrollbar at the bottom** | When zoomed in, move the pointer near the bottom to reveal it; drag the thumb to pan |
| **Ctrl / Cmd + Z** | Undo |
| **Ctrl / Cmd + Y** | Redo |
| **Ctrl / Cmd + A** | Select all |
| **0 / 1** | Set selection to 0 / 1 |

## Mouse

| Action | Effect |
| --- | --- |
| **Drag** | Range selection (or annotation editing) |
| **Right-click** | Context menu |
